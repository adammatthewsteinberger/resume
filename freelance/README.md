# Freelance kit

Everything used to run fixed-scope engagements, kept next to the résumé so the two can't disagree.

| File | What it is | Source |
|---|---|---|
| [../SERVICES.md](../SERVICES.md) | The public catalog: five engagements, their scope, proof and price | Generated |
| [intake.md](intake.md) | The written intake that replaces a discovery call | Hand-written |
| [upwork.md](upwork.md) | Upwork title, overview, skills, portfolio and Project Catalog copy, length-checked | Generated |
| [fiverr-pro.md](fiverr-pro.md) | Fiverr Pro gig titles and descriptions, length-checked | Generated |
| [proposal-template.md](proposal-template.md) | A 150–250 word proposal, plus the reply to a brief too vague to price | Hand-written |
| [message-templates.md](message-templates.md) | Status, risk, scope-change, out-of-scope and handoff messages | Hand-written |

Generated files come from `tools/build_resume.py`; edit the data there and rebuild. The build fails if any platform field passes its character limit, or if a proof line states a number that the résumé does not.

## Rules this kit keeps

- **A person sends every proposal and every message.** No tool logs in, searches or bids on a platform account.
- **Payments for platform clients stay on the platform.** Clients I already know come in through a Direct Contract or my LLC.
- **AI use is disclosed up front,** in the profile, in every gig, and in the intake.
- **Two or three engagements at a time,** each with a written scope and an acceptance checklist.
