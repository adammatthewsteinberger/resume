# Security Policy

This repository contains only my résumé (PDF, DOCX, TXT, Markdown), a Scrum certificate, and the small script that generates those files. There is no application code and there are no releases.

## Reporting a vulnerability

If you find something sensitive here, or a security issue in any of my other repositories:

- Email **adam@matthewsteinberger.com**, or
- Open a **private security advisory** on the affected repository (Security → Advisories → Report a vulnerability).

I'll acknowledge within a few business days. Please don't open a public issue for security reports.
